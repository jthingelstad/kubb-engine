# U.S. National Kubb Championship Rules v2.0

The U.S. championship's rules, copyright 2011, adapted from the World Championship rules
of 2003. They were the rules in force when Kubb On's 2012 and 2013 pieces on doubles,
the fence and the king were written, so they are the text those pieces should be read
against. Where v4.0 (`web-us-rules-v4`) says the same, this file says so briefly.
